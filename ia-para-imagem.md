# ⭐⭐⭐⭐⭐ FLUX (Black Forest Labs)

Status: Minha principal recomendação atualmente.

Modelos:
- FLUX.1 Dev
- FLUX.1 Pro
- FLUX Kontext (edição)

Ideal para:
- Personagens
- Anime
- Stickers
- Emojis
- Concept Art
- PNGs

Pontos fortes:
+ Excelente compreensão de prompt.
+ Ilustrações muito bonitas.
+ Anatomia muito superior ao SDXL.
+ Ótimo para personagens consistentes.
+ Excelente iluminação.
+ Funciona muito bem para assets transparentes.

Onde usar:

https://fal.ai

https://replicate.com

https://www.freepik.com/ai

https://together.ai

# ⭐⭐⭐⭐⭐ ComfyUI

Não é um modelo.

É um ambiente para montar pipelines.

Praticamente obrigatório para quem quer trabalhar sério com IA.

Permite:

✓ FLUX
✓ SDXL
✓ Pony
✓ LoRAs
✓ ControlNet
✓ Inpainting
✓ Upscaling
✓ Background Removal
✓ Segmentação
✓ Face Detailer

Extremamente recomendado.

https://www.comfy.org
